## Curriculum sections relevant to seed nodes (facts only — section names as the source names them)

1. **HF Agents Course** (https://huggingface.co/learn/agents-course/unit0/introduction): Unit 0 Welcome/syllabus/paths; Unit 1 Introduction to Agents (concepts, LLMs recap, tools, CodeAgents vs tool-calling); Unit 2 Frameworks — 2.1 smolagents, 2.2 LlamaIndex, 2.3 LangGraph; Unit 3 Use Case Agentic RAG; Unit 4 Final Project (build/test/certify agent on GAIA benchmark); Bonus 1 fine-tuning an LLM for function-calling; Bonus 2 agent observability and evaluation; Bonus 3 agents in games (Pokemon). Quizzes/live sessions/Spaces per unit.
2. **DSPy** (https://dspy.ai/): Getting Started (Program-don't-prompt, setup, first program, signatures incl. class-based/expanding, modules, Tools with ReAct, composing modules, metrics, GEPA optimization, saving/loading); Diving Deeper (signatures depth, custom modules, built-in variants, RLM, Flex optimizable code, Tools and MCP, ReAct/ReActV2, metrics+eval, optimizer choice, GEPA depth, BootstrapFewShot family, adapters, settings/context); Tutorials (conversation history, agents, RAG incl. multi-hop and RAG-as-agent, entity extraction, classification, math reasoning, classification finetuning, advanced tool use, program-of-thought, image/audio); API reference.
3. **LangGraph** (https://docs.langchain.com/oss/python/langgraph/overview): graphs/state/reducers; persistence + long-term memory; streaming (token + intermediate steps); human-in-the-loop; branching/subgraphs; multi-agent orchestration; prebuilt ReAct agent; checkpointing (sqlite/postgres); templates for common agentic workflows; LangGraph Studio (visual debug); LangGraph Platform deployment (APIs, threads, cron, task queues); LangSmith evals/observability; LangChain Academy intro-to-langgraph.
4. **smolagents** (https://huggingface.co/docs/smolagents): CodeAgent (code actions, composability) vs ToolCallingAgent; guided tour/quickstart; tools in-depth guide (authoring, Hub Spaces as tools, LangChain/MCP interop via `from_langchain`/`from_mcp`); secure code execution (E2B/Modal/Blaxel/Docker sandboxes); agent memory management; telemetry/inspection; examples (self-correcting Text-to-SQL, agentic RAG knowledge base, multi-agent orchestration, vision web-browser agent); models (InferenceClientModel incl. providers, LiteLLMModel 100+ LLMs, TransformersModel local, OpenAI-compatible servers); CLI (`smolagent`, `webagent`).
5. **LlamaIndex** (https://developers.llamaindex.ai/python/framework/): documents/nodes/indices; ingestion; RAG pipeline; retrievers/query engines; agents (ReAct, function-calling, workflows event-triggered); Workflows; LlamaParse (agentic OCR, 130+ formats) / LiteParse; LlamaExtract (structured extraction); LlamaCloud Index/Split; LlamaAgents + Agent Builder; LlamaHub connectors (300+ integrations); MCP (`llama-index-tools-mcp`, docs MCP server); observability (Arize Phoenix, Langfuse, W&B, OpenTelemetry); evals; ParseBench benchmark.
6. **MCP** (https://modelcontextprotocol.io/): intro/getting-started; base protocol (JSON-RPC 2.0, lifecycle, capability negotiation); authorization (OAuth/OIDC for HTTP transports); server features — Resources, Prompts, Tools (incl. structured output, icons metadata); client features — Sampling, Roots, Elicitation; utilities (logging, progress, cancellation, completion); transports (stdio, Streamable HTTP); extensions — Tasks (async long-running), Skills-over-MCP, MCP Apps (inline UI); schema per revision (`schema/<date>/schema.ts|.json`).
7. **Microsoft Agent Framework** (https://learn.microsoft.com/en-us/agent-framework/): agents overview (chat clients incl. Azure OpenAI/OpenAI/Anthropic/Ollama); function tools + MCP servers as tools; workflows (sequential, concurrent, handoff, group collaboration; graph-based orchestration); session-based state management; middleware/filters; type safety; declarative YAML agents; Agent Skills; observability (OpenTelemetry); hosting (Azure Functions/durable, Foundry hosted agents); migration guides from Semantic Kernel and from AutoGen; FAQ/support.
8. **OpenAI Agents SDK** (https://openai.github.io/openai-agents-python/ + https://developers.openai.com/api/docs/guides/agents): quickstart (install, API key, first agent+run); Agents; Runner (sync/async); handoffs (agents-as-tools, delegation); guardrails (input/output); sessions/memory; function tools + MCP servers; tracing; context/dependencies; models (Responses + Chat Completions + 100+ via LiteLLM/any-llm); sandbox execution + harness/memory-orchestration (Apr-2026 update); realtime API (JS surface; Python seed should cite only verified Python pages).
9. **PydanticAI** (https://pydantic.dev/docs/ai/): agents; dependencies; function tools + toolsets; structured output; capabilities (tools+hooks+instructions+settings bundle); models overview (string-swap providers); MCP; instructions/system prompts; hooks; durable execution (Temporal); evals (pydantic-evals, pytest-style); testing (built-in `test` model); instrumentation/OTel + Logfire; realtime voice/image-generation/embeddings; interfaces (web UI, CLI, voice call, background queue); Harness index + coding-agent skills; upgrade guide V1→V2; version policy.
10. **FastAPI** (https://fastapi.tiangolo.com/): Tutorial/User Guide (path/query/body, validation, dependencies, security, background tasks, WebSockets, testing, OpenAPI/Swagger+ReDoc); Advanced (lifespan, middleware, sub-apps, proxies, settings); Deployment — versions pinning (`About FastAPI versions`: 0.x, pin MINOR), manual server run, Uvicorn workers, containers (`FastAPI in Containers - Docker`), cloud providers, HTTPS; Reference (FastAPI class, routing, responses, middleware, TestClient); Release Notes.
11. **Docker Engine + alternates**: Engine (https://docs.docker.com/engine/) — architecture (dockerd daemon, API, `docker` CLI), images/containers/networks/volumes, Compose, BuildKit builds, apt-repo install, binaries, stable vs test channels; Desktop license (https://docs.docker.com/subscription-billing/desktop-license/) — free vs paid gates (NOT the primer default); Podman (https://docs.podman.io) — daemonless/rootless, Quadlet/systemd, Compose compat; Rancher Desktop (https://rancherdesktop.io/) — k3s + kubectl/Helm, version-selectable k8s; Finch (https://runfinch.com/docs/getting-started/installation/) — `finch run/build/compose`, ECR auth; Colima (repo README) — `colima start`, docker-socket passthrough, `--kubernetes` k3s opt-in.
