# View and search file contents from the command line

## What this skill is

Print a file, page through a long one, and search within it for a pattern from the terminal — the fast way to answer ‘what’s in this file?’ without opening an editor — and state what was found.

## Why this skill

Fast file reading is the daily lookup everything else is built on.

## What passing requires

See the artifact spec and validation gate in `evidence/` for this node (`spec.tooling.cli.inspecting_files`); Evidence is judged by learner manual review. The body does not restate them.

## How to work on it

Study the view-and-search commands first, then view and search a real file and write down what the contents mean. Seed estimate: 20–45 minutes.
