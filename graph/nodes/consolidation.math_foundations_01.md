# Solve a mixed math-foundations problem set

## What this skill is

Work a problem set that deliberately mixes percentages and ratios, order of operations, linear equations, and linear functions — without the section headings that tell you which technique to reach for. Show the work, not just the answers, so the reasoning is visible.

## Why this skill

The skill this weaves is selection: recognizing from a bare problem which foundation applies, then applying it cleanly. Real problems never arrive labeled by chapter, so this integration is what turns drilled techniques into usable mathematics.

## What passing requires

See the artifact spec and validation gate in `evidence/` for this node (`spec.consolidation.math_foundations`); Evidence is judged by learner manual review. The body does not restate them.

## How to work on it

Pull a few problems each from the woven bands, shuffle them before solving, and use mixed-review and unit-test exercises rather than single-topic drills. Seed estimate: 60–120 minutes.
