# Produce a dataset analysis report portfolio project

## What this skill is

Pick a dataset, ask a real question of it, and answer that question with a Pandas analysis — loading, grouping, and aggregating the data — then deliver a report: the finding stated plainly, at least one chart that earns its place, an honest account of what the data does and does not support, and the notebook or script that reproduces the numbers.

## Why this skill

An analysis only counts when a reader can trust it and reproduce it: finding, evidence, chart, limits, and code together.

## What passing requires

See the artifact spec and validation gate in `evidence/` for this node (`spec.portfolio.project.dataset_analysis_report`); Evidence is judged by learner manual review. The body does not restate them.

## How to work on it

Run the group-and-aggregate analysis first, make the chart honest and readable, then write the report prose with each claim naming the evidence under it. Seed estimate: 120–300 minutes.
